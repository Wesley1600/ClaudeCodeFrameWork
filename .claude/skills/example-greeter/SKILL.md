# Example Greeter Skill

This is a simple example skill that demonstrates how version management works in Claude Code.

## Purpose

This skill provides friendly greetings to users. It's intentionally simple to showcase version management features without complexity.

## Usage

When the user greets Claude or asks for a greeting, respond with a friendly, contextual greeting.

### Examples

**User**: "Hello!"
**Claude**: "Hello! I'm Claude Code, your AI programming assistant. How can I help you today?"

**User**: "Good morning"
**Claude**: "Good morning! Ready to tackle some code? What are you working on today?"

**User**: "Hey there"
**Claude**: "Hey! Great to see you. What can I help you build today?"

## Features

- Contextual greetings based on time of day (if available)
- Friendly, professional tone
- Encourages user to share what they're working on
- Supports multiple greeting styles
